# 聊一下动态 QQ 助手

这个 AstrBot 插件面向 **个人 QQ 号 + NapCat + OneBot v11 反向 WebSocket + AstrBot** 场景，不是 QQ 官方机器人号接入。它只开放论坛“动态”能力，不提供帖子、文章、内容详情等功能。

## 能力

- DeepSeek 聊天：插件调用后端 `/SFreeBot/chat`，DeepSeek Key 留在后端配置表。
- QQ 绑定论坛账号：个人 QQ 账号收到用户消息后发送绑定页链接，用户用论坛账号密码登录后完成绑定，不创建普通登录 token，也不修改 `authCode`。
- 动态工具：发动态、修改资料、查询积分/签到状态、签到。
- QQ 图片动态：插件优先读取 NapCat 本地图片，必要时调用 `get_image`，再由论坛后端上传为永久图片 URL；不会把 `multimedia.nt.qq.com.cn` 临时地址直接写入动态。
- 群同步：后台或群命令登记群后，同步最新公开通过审核的动态，包含动态 H5 链接、图片和摘要。
- 群内引用评论：引用云云同步的动态并直接输入评论，使用当前 QQ 已绑定的论坛账号同步到论坛；未绑定时保留评论并发送绑定链接。
- QQ 空间每日图集：按论坛后台设定的北京时间，每条公开已审核动态生成一张带 `P1-P9` 编号的 1080px 图片；批次数量和简短正文由后台控制，插件通过 NapCat 获取当前个人 QQ 的空间凭据，上传图片并调用 QQ 空间发布接口。
- 自然语言流程：支持“帮我发个动态”“签到顺便看看积分”“把昵称改成小明”，缺少内容时会继续追问。
- 持久化会话：动态草稿、资料修改、绑定续接和最近聊天记录保存在 AstrBot 插件数据目录，插件重启后仍可继续。

## 使用方式

用户不需要记命令，可以直接说：

- `帮我发个动态`
- `签到顺便看看积分`
- `把昵称改成小明`
- `绑定论坛账号`

旧命令继续兼容：

- `/动态助手`
- `/绑定论坛`
- `/我的状态`
- `/签到`
- `/发动态 今天食堂二楼不错`
- `/修改资料 昵称 新昵称`
- `/绑定本群同步`

发动态和修改资料会先生成预览。发动态时，文字和图片可以同一条消息发送，也可以在预览前后分多条、任意顺序发送；插件会持续合并草稿，最后回复 `确认`、`发吧`、`继续` 或 `可以` 才会发布。回复 `取消` 会清空整份草稿。如果确认时尚未绑定，草稿不会丢失；绑定完成后回复 `好了`，插件会恢复原操作并再次确认。

带图动态最多 9 张、单张最多 8 MB，支持 JPEG、PNG、GIF 和 WebP。图片读取或上传失败时不会降级成纯文字发布，草稿会保留，用户可重新发送图片后重试。

插件处理私聊或命令后会终止 AstrBot 默认 LLM 流程，避免同一条消息出现默认模型与论坛助手重复回复。

## 配置

在 AstrBot 插件配置里设置：

- `backend_base_url`：论坛后端地址。
- `bot_secret`：与后台 QQ Bot 设置中的 Bot Secret 完全一致；后台未设置时才使用服务器环境变量 `LCXQY_QQBOT_SECRET`。
- 群聊普通对话开关：在论坛后台 `QQ Bot设置 -> 群聊普通对话` 控制。关闭后群里闲聊不回复，但动态同步、引用动态评论和明确的论坛操作仍可用。
- QQ 空间设置：发布时间、批次数量、摘要长度、是否使用动态首图、标题/副标题/底部文案、简短说说正文、可见范围、配色和背景图均在论坛后台 `QQ Bot设置 -> QQ 空间每日同步` 控制。

群同步会自动识别当前 AstrBot 的 OneBot 适配器 ID，不需要手填 `unified_msg_origin`。首次启用某个群时只发送当前最新一条动态，随后按游标增量同步，避免补发全部历史动态。

QQ 空间同步按后台选择的模式执行。首次启用取最新一批动态，之后只读取上次成功游标之后的内容；立即发布也遵守同一个游标，不会重新发送已发布动态。每条动态生成一张独立图片，按 `P1-P9` 标号，一条说说最多发布 9 张；不足批量上限时有几条发几条，不等待凑满。说说正文只使用后台填写的简短文案，不再自动追加 P 编号、作者和摘要清单。NapCat 只负责提供当前个人 QQ 的 `get_cookies` 凭据，插件直接调用 QQ 空间图片上传和发布接口，不依赖不存在的 `send_qzone_msg` 动作。没有新动态时不发，失败不推进游标，15 分钟后可重试。远程图片限制为公网 HTTP(S)、单张最多 8 MB，下载失败会退回纯色文字版。

普通聊天使用“云云”人设：亲切、机灵、略微傲娇，偶尔自然带一句“喵”。默认只回复一到三句短句，不写大段动作描写，也不会把成人露骨内容带入校园论坛场景。论坛相关表达始终以“动态”为唯一内容入口。

群聊触发规则由后台 `群聊普通对话` 控制。开启时，只有 @云云、直接叫“云云”、引用云云上一条消息，或正在继续绑定/发布/修改等操作时，云云才会回应；关闭时，普通闲聊和纯 @ 不回复，但论坛操作、引用动态评论和群动态同步不受影响。

后端后台 `QQ Bot设置` 里维护 DeepSeek Key、工具开关、同步群和 H5 链接。新增同步群时只需填写群号，群名可选；平台固定为 `qq`，消息来源由插件按当前 OneBot 适配器自动确定，游标自动推进。这里的“Bot”指 NapCat 登录的个人 QQ 号自动化助手，不是官方 QQBot。

论坛插件只应安装在承担论坛 Bot 的 AstrBot 实例上。如果 NapCat 同时连接本机和服务器 AstrBot，不要在两个实例中同时启用本插件。
